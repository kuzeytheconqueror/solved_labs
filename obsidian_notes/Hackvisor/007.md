## Remote Desktop Protocol (RDP)
Remote Desktop Protocol (RDP) is a protocol developed by Microsoft that
allows users to remotely access another computer over a network. RDP is
equipped with security and functionality features such as data encryption,
session management and device routing.

## Information Gathering
Let's start gathering information by doing a port scan of our target machine.

```bash

```

As a result of the port scan, we discover that 4 ports are open. When we did
research on the open port 3389, we found that the RDP service is running,
through which we can establish a remote desktop connection to the
computer.

## Task 1

We can get the hostname of the target machine through the NetBIOS
service. For this we can simply use the `nmblookup` tool.

```bash
nmblookup [options] <netbios-name>
```

- `-A` — This parameter is used to learn the NetBIOS name of a computer
  from its IP address.
- `-B` — This parameter is used to learn the IP address of a computer
  from its NetBIOS name.
