# What Are the Types of XSS Attacks?
> **Category:** Cross-Site Scripting (XSS) · **Source:** [PortSwigger Web Security Academy](https://portswigger.net/web-security/cross-site-scripting)

There are three main types of XSS attacks:

| Type | Where the malicious script comes from | Notes |
|---|---|---|
| **Reflected XSS** | The current HTTP request | [[05_Reflected cross-site scripting]] · [[11_What is Reflected XSS]] |
| **Stored XSS** | The website's database | [[06_Stored cross-site scripting]] · [[21_Stored XSS]] |
| **DOM-based XSS** | Client-side code, not server-side code | [[07_DOM-Based cross-site scripting]] · [[31_DOM-based XSS]] |
